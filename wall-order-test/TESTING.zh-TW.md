# 測試步驟

[English](TESTING.md) · [回到說明](README.zh-TW.md)

目標是公平的 A/B/C 比較：三次列印**只有**牆的設定不同。仔細的一組比很多組隨便印的更有用。

## 1. 選模型

[`models/`](models) 裡的**試片**都是 15 mm 高的方塊，四邊都有往下的倒角，Y 方向有一條貫穿的槽（槽頂是橋接），X 方向有一個 5 mm 的貫穿孔。

| 檔案 | 倒角 | 寬度 | 說明 |
| --- | --- | --- | --- |
| `453MF.3mf` | 45° | 25 mm | 倒角從列印板開始，就像一般零件的底邊倒角。 |
| `603MF.3mf` | 60° | 25 mm | 同上，比較陡。 |
| `753MF.3mf` | 75° | 35 mm | 同上，非常陡。 |
| `*_底座3mm.3mf` | 相同 | 相同 | 同一個方塊放在 3 mm 的垂直底座上，讓倒角離開第一層和象腳補償的範圍。**建議先從這幾個開始**，`603MF_底座3mm.3mf` 很適合第一次測試。 |

也歡迎用**你自己的模型**，特別是會出現這個功能想解決的問題的模型。能分享就附上，不能分享就描述一下。

## 2. 切三個版本

用你平常的印表機、線材和列印參數設定，**只在全域列印參數**（不是物件設定）改下面這些：

| 列印 | 牆列印順序 | 依照懸空角度改變牆順序 | 這個功能的其他選項 |
| --- | --- | --- | --- |
| **A** | 你平常用的（內牆/外牆/內牆 或 外牆/內牆） | 關 | – |
| **B** | 內牆/外牆 | 關 | – |
| **C** | 和 A 相同 | **開** | 懸空處使用內牆/外牆 = **40°**，其他維持預設 |

想試其他數值，歡迎多印幾組（D、E…），請記下改了什麼。

A、B、C 之間其他都不要改：速度、冷卻、流量、溫度、接縫、擺放位置和方向。**每盤只放一個物件**，每次放在同一個位置。物件數量會改變每層時間和吹風條件，所以一盤放好幾個試片不算公平比較。

每次切完都要存檔（**匯出 G-code**，或用 **匯出單一列印板切片檔案** 得到內含 G-code 的 3MF），分別命名為 `A.gcode`、`B.gcode`、`C.gcode`。

列印前，先把 `C.gcode` 拖進 [`tools/wallorder-check.html`](tools/wallorder-check.html)，確認它顯示「測試版」，而且倒角處有切換的層。如果沒有任何層切換，代表設定沒有生效，印 C 就沒有意義。

## 3. 列印

- A、B、C 接連印，用同一卷線材，印表機狀態相同（機箱門開關一致、同一個房間）。
- 記下任何異常：堵頭、錯層、有風、冷機啟動。
- 有空的話：同一組印兩次，第一次照 A B C 的順序，第二次照 C B A。

## 4. 拍照

在貼著列印板的那一面用筆標上 A/B/C，或放在寫了標記的紙上。

請拍下列照片，**三個零件放在同一張照片裡**、光線相同：

1. **倒角的下側**：從低角度往上看，光從側面斜照，最能看出下垂和翹邊。
2. **跨過切換處的側面**：倒角開始和結束位置上下方的垂直牆面，看順序切換的地方有沒有線條或色差。
3. 任何看起來不一樣的地方的特寫。

手機拍就可以。除了裁切之外不要修圖。

## 5. 評分

比較 **C 和 A**、**C 和 B**：

| 問題 | 回答 |
| --- | --- |
| 倒角下側：C 和 A 比 | 好很多 / 較好 / 一樣 / 較差 / 差很多 |
| 倒角下側：C 和 B 比 | 好很多 / 較好 / 一樣 / 較差 / 差很多 |
| C 上順序切換處看得到線嗎 | 沒有 / 很淡（斜光下才看得到）/ 看得到 / 很明顯 |
| 遠離倒角的垂直牆面：C 和 A 比 | 一樣 / 不同（請描述） |
| 你會留哪一個 | A / B / C / 沒差 |

如果能請別人在**不知道哪個是哪個**的情況下排序，請在回報中註明，盲測的排序是最有力的證據。

有空的話可以量尺寸：用卡尺量 A、B、C 在倒角區和垂直區的寬度。

## 6. 回報

開一個 **Print report**（Issues → New issue → Print report），附上：

- 照片
- `A.gcode`、`B.gcode`、`C.gcode`（或切片後的 3MF）**放在同一個 zip**；GitHub 不接受直接上傳 `.gcode` 或 `.3mf`
- 如果用了自己的模型而且可以分享，也一起附上

G-code 會包含你的印表機和線材設定，包括開始/結束 G-code。如果裡面有你不想公開的內容，請先檢查一下。
