# 依照懸空角度改變牆順序：公開測試版（非官方）

[English](README.md)

> **這不是 OrcaSlicer 官方版本。** 這是 OrcaSlicer 使用者以官方 **v2.5.0-alpha** 加上一個功能所做的測試版，目的是在向官方提出之前，先蒐集真實的列印結果。這個版本的問題請回報在這裡，不要回報給 OrcaSlicer 官方。

## 這個功能做什麼

牆列印順序用 **內牆/外牆/內牆** 或 **外牆/內牆** 時，懸空處（往下的倒角、圓角底邊）的外牆會在旁邊還沒有內牆的情況下先印出來，所以容易下垂。改用 **內牆/外牆** 可以解決，但整個物件的表面都會跟著改變。

這個測試版**只把需要的層**改成內牆/外牆，其他地方維持你原本的順序：

- 某個區塊相對下一層的懸空超過設定角度的層
- 從物件底部算起、在設定高度以下的層
- 被象腳補償縮小的層

判斷是以每一層的每個獨立區塊為單位。物件的第一層一定不會切換。主開關關閉時，切出來的結果和官方 v2.5.0-alpha 相同，這點已經逐行比對過，你也可以自己驗證（見[檢查 G-code](#檢查-g-code)）。發佈前做過的軟體測試列在 [SOFTWARE_TESTS.md](SOFTWARE_TESTS.md)（英文）。

**想知道的是：** 在你的印表機上，懸空是不是真的印得比較好？牆順序切換的地方明不明顯？結果變差也一樣有價值。

## 下載與安裝（和平常用的 OrcaSlicer 分開）

到本倉庫的 **Releases** 頁面下載。每個版本都會寫明對應的原始碼 commit 和 SHA-256 校驗碼。

| 系統 | 檔案 | 如何和平常用的分開 |
| --- | --- | --- |
| Windows | `OrcaWallOrderTest-..._portable.zip` | 解壓後執行 `OrcaWallOrderTest\orca-slicer.exe`。旁邊的空資料夾 `data_dir` 會保存所有設定，不會動到你已安裝的 OrcaSlicer。如果 Windows 說路徑太長，請解壓到短一點的位置，例如 `C:\OrcaWallOrderTest`。 |
| macOS | `.dmg` | 把 `OrcaSlicer.app` 複製到一個**新資料夾**，並在 app 旁邊建立一個名為 `data_dir` 的空資料夾。這個版本沒有簽章，第一次開啟請在 app 上按右鍵 → 打開（或執行 `xattr -cr OrcaSlicer.app`）。 |
| Linux | `.AppImage` | 用獨立的設定資料夾啟動：`./OrcaSlicer*.AppImage --datadir ~/orca-wallorder-test` |

要用自己的印表機和線材設定，請在平常用的 OrcaSlicer 用 **檔案 → 匯出 → 匯出設定檔組** 匯出，再匯入測試版。建議測試版不要登入雲端帳號，或至少關閉預設同步，免得多出來的設定跑進你平常的設定裡。官方版會直接忽略這些設定，但分開比較不會混淆。

全新的設定資料夾在 Windows 上可能會要求安裝 **Bambu 網路外掛**。只有 Bambu 印表機的網路功能需要它，測試時選「暫時略過」即可。

## 設定項目

位置在 **列印參數 → 品質 → 牆與表面**，就在 **牆列印順序** 下方。這些是進階設定，請打開列印參數面板上的 **進階** 開關。也可以像其他品質設定一樣，針對單一物件或高度範圍修改器設定。

| 設定 | 預設 | 作用 |
| --- | --- | --- |
| **依照懸空角度改變牆順序** | 關 | 主開關，打開後才顯示下列選項。牆順序已經是內牆/外牆、螺旋花瓶模式或沒有牆時會隱藏。 |
| **懸空處使用內牆/外牆** | 0° | 區塊相對下一層的懸空超過這個角度時切換。角度從垂直方向算起：0° 是垂直牆，45° 是常見的倒角。請設得比想抓的倒角小一點，例如 45° 倒角設 **40°**。0 = 關閉。 |
| **使用內牆/外牆的懸空角度上限** | 0° | 最陡的懸空超過這個角度的區塊維持原本順序，適合非常陡的懸空用原順序反而比較好的情況。只在大於上一項時有作用（上一項為 0 時會變灰）。0 = 不設上限。 |
| **此高度以下使用內牆/外牆** | 0 mm | 從物件底部到這個高度的每一層都切換（第一層除外）。適合圓角或倒角的底邊。0 = 關閉。 |
| **象腳補償層使用內牆/外牆** | 關 | 切換被象腳補償縮小的層（第一層除外）。只有在補償大於 0、補償超過一層、而且沒有使用筏層時才能開。 |
| **被切換的層使用精準外牆尺寸** | 關 | 只對被切換的區塊套用精準外牆尺寸（消除內牆和外牆的重疊，避免外牆被往外推）。和官方的 **精準外牆尺寸** 選項互相獨立。 |
| **被切換的層內縮補償** | 0 mm | 把被切換的區塊縮小，抵銷先印的內牆把外牆往外推的量。**數值是兩側合計**：0.2 mm 代表每一側內縮 0.1 mm（和象腳補償的「每側」不同）。孔會放大同樣的量。 |

## 怎麼測（大約 1–2 小時的列印）

完整步驟和評分表見 **[TESTING.zh-TW.md](TESTING.zh-TW.md)**。簡單說：

1. 選一個模型：[`models/`](models) 裡的六個試片（45°、60°、75° 倒角，各有加不加 3 mm 底座兩種），或你自己有下垂問題的模型。
2. **印三次**，只改牆的設定：
   - **A**：你平常的牆順序（內牆/外牆/內牆 或 外牆/內牆），功能關閉
   - **B**：牆列印順序 = **內牆/外牆**（整個物件），功能關閉
   - **C**：你平常的牆順序，功能**打開**（例如懸空處使用內牆/外牆 = 40°）
3. 三次都用同一台印表機、同一卷線材、同樣速度，擺在列印板同一位置、同一方向。每盤只放一個物件。
4. 三個放在一起、在同樣光線下拍照：從下方拍懸空處，再拍順序切換處的側面。
5. 開一個 **Print report**（列印回報）issue，附上照片，以及三個 G-code 檔（或專案 3MF）的壓縮檔。

## 檢查 G-code

[`tools/wallorder-check.html`](tools/wallorder-check.html) 是離線網頁工具，下載後用瀏覽器打開即可，不會上傳任何東西。

- 拖入一個 G-code：顯示是哪個版本、哪些設定切出來的，以及哪些層用內牆/外牆印。
- 拖入**兩個** G-code 可以比對。主開關關閉時，測試版和官方 v2.5.0-alpha 切出來的移動應該完全相同；如果發現不同，請回報。

## 已知的現象（不是錯誤）

以下是軟體測試中發現的現象，大部分在官方版改變牆順序時也會發生。

- **接縫起點可能移動**：被切換的層和相鄰的層都可能發生。接縫位置設「最近」或「背面」時，起點會跟著噴頭位置走；設「對齊」時會上下層一起對齊。每一圈牆和擠出量都相同，只有起點不同。
- **絨毛表面是隨機的**：官方版每次切片結果也都不同。牆順序是內牆/外牆時，官方版的絨毛外牆會變長、內牆變短，被切換的層也一樣。
- **整個區塊一起切換**，不是只切換某一段牆。
- **扭轉多邊形孔**可能被判定成懸空。
- 設定和物件不同的**高度範圍修改器**會把物件拆成多個區域。不論有沒有這個功能，官方版都會因此讓這個物件的牆出現輸出捨入的差異（0.001 mm）。
- 只有一圈牆、螺旋花瓶模式、或牆順序已經是內牆/外牆時**沒有作用**。
- 順序改變的地方可能留下**看得見的線**，這正是這次測試想量測的項目之一。

## 問題回報

當機、切片失敗、或設定行為和說明不符：請開一個 **Problem report**（問題回報）issue。請先試試看官方 v2.5.0-alpha（或本版關閉主開關）是否也有同樣問題；如果有，就不是這個功能造成的。

## 結果會怎麼使用

所有回報（包括結果不好的）都會在本倉庫公開彙整。如果證據支持，這個功能會以 pull request 的形式提給 OrcaSlicer，並附上這些回報的連結。什麼程度才算證據足夠，請見 [EVIDENCE.zh-TW.md](EVIDENCE.zh-TW.md)。這裡的任何內容都不代表 OrcaSlicer 團隊認可或會接受這個功能。
