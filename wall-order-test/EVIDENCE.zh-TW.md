# 回報如何計算

[English](EVIDENCE.md) · [回到說明](README.zh-TW.md)

這些規則在結果出來**之前**就先寫好，避免彙整時為了想要的結論去調整。如果規則有修改，會在本文最後記錄修改內容和原因。

## 符合下列條件的回報才計入

1. 同一台印表機、同一個模型的 A、B、C 三次列印，照 [TESTING.zh-TW.md](TESTING.zh-TW.md) 的步驟（或說明哪裡不同）。
2. 附上三次的 G-code（或切片 3MF），並且檢查工具確認：
   - A 和 C 來自測試版（或 A/B 來自官方 v2.5.0-alpha），除了牆的選項之外設定相同；
   - C 在懸空處有切換的層。
3. 照片裡三個零件放在一起。

不符合條件的回報一樣會閱讀、保留，並另外列為「不完整」，不會默默略過。

## 彙整的內容

每份計入的回報記錄：印表機類型與韌體、噴嘴、材料、層高、牆產生器、模型、功能設定、TESTING 的五個評分（倒角下側 C 比 A、C 比 B、切換線、垂直牆面、會留哪個），以及是否盲測。

彙整會列出**所有**結果，包含較好、一樣和較差；並以測試者為單位計算，不是以零件數計算，所以一個人印十組不會蓋過十個人的結果。

測試者回報的軟體檢查（「功能關閉 = 官方」、當機、切換錯誤）另外列出。

## 何時提交給 OrcaSlicer（草案）

以下**全部**成立時，才把功能提交給官方：

- **至少 8 位獨立測試者**有計入的回報；
- **至少 3 種印表機類型**（例如床動式、CoreXY、Bambu Lab、Klipper、Marlin），**至少 2 種材料**；
- 倒角下側：**明顯多數的測試者認為 C 比 A 好**，而且 C 很少比較差；
- 多數測試者認為 C 的切換線「沒有」或「很淡」，或者回報能看出哪些設定可以避免；
- 沒有尚未解決、由這個功能造成的當機或輸出錯誤回報；
- 「功能關閉 = 官方 v2.5.0-alpha」由**至少 3 位、使用至少 2 種作業系統**的測試者確認。

如果證據顯示這個功能沒有幫助，或只在少數情況有用，這個結果一樣會公開，提交內容也會因此修改或取消。

提交給官方的 pull request 只會包含功能本身的 commit（並移除作者早期自用原型的格式相容程式），並附上這份彙整的連結。
